# Linear-Regression

## Dependencies
- numpy
- pandas
- matplotlib
- seaborn
- scikit-learn

---

## Описание

Проект представляет собой реализацию **линейной регрессии с нуля** на языке Python с использованием только библиотеки NumPy.

В ходе работы были реализованы следующие ключевые элементы:

- Градиентный спуск для обучения модели
- Функция потерь MSE (Mean Squared Error)
- Метрики оценки качества: MAE, MSE, RMSE, MAPE, R²
- Сравнение с эталонной реализацией из `sklearn`

---

## Цель проекта

Основная цель — продемонстрировать понимание внутреннего устройства линейной регрессии, градиентного спуска и ключевых методов оценки качества моделей машинного обучения для задач регрессии.

---

## Данные

- **Источник:** синтетический датасет, сгенерированный с помощью `make_regression` из библиотеки `sklearn`
- **Количество объектов:** 2000
- **Количество признаков:** 5
- **Целевая переменная:** непрерывная

---

## Методология

### Архитектура модели
- Модель: **Линейная регрессия** (реализована вручную)
- Функция потерь: **MSE (Mean Squared Error)**
- Оптимизация: **градиентный спуск**

### Оценка качества
- Метрики: **MSE, RMSE, MAE, MAPE, R²**
- Сравнение с `LinearRegression` из `sklearn`
- Анализ остатков для проверки гетероскедастичности

---

## Результаты

| Метрика | Значение |
| :--- | :--- |
| **MSE** | 101.41 |
| **RMSE** | 10.07 |
| **MAE** | 11.11 |
| **R²** | 0.98 |

**Вывод:**  
MAPE оказался неинформативным из-за наличия в целевой переменной отрицательных и близких к нулю значений.  
При этом значения R² на обучающей и тестовой выборках совпадают, что свидетельствует об отсутствии переобучения и подтверждает стабильность модели.

---

## Заключение

В ходе работы была реализована линейная регрессия с нуля, обучена на синтетических данных и оценена с помощью различных метрик. Модель показала стабильные результаты, сравнимые с эталонной реализацией из `sklearn`. Отсутствие переобучения подтверждается близкими значениями R² на Train и Test выборках.
